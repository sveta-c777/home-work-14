Accordion

Build vertically collapsing accordions with native HTML <details> and <summary> elements.

Example

Click the accordions below to expand/collapse the accordion content. Each <details> element shares the same name attribute value, creating an exclusive accordion where opening one item automatically closes the others.

Accordion Item #1
This is the first item's accordion body. It is shown by default because the open attribute is present. The native <details> element handles all the show/hide logic without any JavaScript. You can put any HTML content within the .accordion-body.
Accordion Item #2
This is the second item's accordion body. The name attribute groups this with other accordion items.
Accordion Item #3
This is the third item's accordion body. This exclusive accordion behavior is built into the browser — no Bootstrap JavaScript required. When you open this item, any other open item in the same group will close automatically.
Accordion Item #4
This is the third item's accordion body. Just use matching name attributes on your <details> elements.
Accordion Item #5
This is the third item's accordion body. The panel height animation needs interpolate-size. Browsers without it open and close the panel at once. See Transitions to change the timing or to remove it.
